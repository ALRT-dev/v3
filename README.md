# v3 — archive of the launched ALRT app

Snapshot of **`SafetyALRT/alrtap-frontend` v1.0.4+34** — the version of the
ALRT app that is live in the stores — kept here as
`alrtap-frontend-main (1).zip` (the `claude/alert-screens-design-api-qhox3m`
branch holds the same tree unzipped).

Its only differences from `ALRT-dev/V2-Claude` are two deliberate production
hides, both since ported to `ALRT-dev/widget`:

- the "Live Alerts / Learn" toggle on the notifications screen (content
  experience not finalised), and
- the Spanish language tile in the profile (app not yet localised).

**Do not develop here.** Active development is in `ALRT-dev/widget`
(v1.0.5+35, all V2 features); the backend is `ALRT-dev/backendV2`
(api.safetyalrt.com).
